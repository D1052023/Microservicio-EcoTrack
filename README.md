# EcoTrack

MVP web para registrar actividades diarias en lenguaje natural y estimar huella de carbono.

## Requisitos

- Node.js 18+
- npm

## Ejecución

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Pruebas

```bash
npm test
```

## Ejemplo de uso

Escribe en el campo de texto:

```
Hoy comí carne y viajé 20 km en bus
```

Y pulsa **Analizar actividades**.
